## 原线程处置依据

以下记录三条意见的修复依据和保留边界；对应实现为包含本文的提交，发布回复时在各原线程附上提交编号与门禁结果。

### [图像属性文法](https://github.com/hailingu/PlotWeave/pull/288#discussion_r4069702047)

1. **处置** — 已修复，真实缺陷，P2。原实现确实错误放行边框、轮廓和文字阴影等属性上的图像值。
2. **理由与变更** — `colorTypeOk` 先按属性限制渐变/URL，再检查颜色成分。背景可使用图像；SVG `fill`/`stroke` 的合法 URL 绘制引用保留，CSS 渐变仍拒绝。设计说明已同步到 §2.1。
3. **验证** — 图像属性 7 个正反用例通过；聚焦套件 51/51、完整前端路由和 1893 个测试全部通过，命令见上。未运行真实 WebView 像素验证。
4. **后续** — 本条修复无后续工作。完整 CSS 文法仍属于已披露的静态模型边界。

### [fallback 类型校验](https://github.com/hailingu/PlotWeave/pull/288#discussion_r4069702052)

1. **处置** — 已修复，真实缺陷，P2。`color: var(--missing, 4px)` 现在会按无效消费值报告。
2. **理由与变更** — `resolveDisplayValue` 解析完整的嵌套 `var()`，优先选择有效主值，否则解析 fallback；保证无效、断链和循环的自定义属性进入回退。`variableCycles` 将 fallback 中的依赖纳入环检测，独立空回退由类型校验拒绝。
3. **验证** — 14 个 fallback 正反用例通过，包含嵌套回退、函数参数逗号、有效主值带无效回退、initial、断链、直接/间接循环及空值；聚焦和完整路由检查结果见上。
4. **后续** — 本条修复无后续工作。既有接线扫描规则未扩展为完整 CSS 求值引擎。

### [逐选择器分支解析](https://github.com/hailingu/PlotWeave/pull/288#discussion_r4069702059)

1. **处置** — 已修复，真实缺陷，P2。各分支局部遮蔽不再因无法单独覆盖整个逗号选择器而被丢弃。
2. **理由与变更** — 全表扫描统一调用 `displayTypeErrors`，按活跃环境及每个选择器分支调用 `displayValueIn`；局部同名定义只覆盖可达分支，其他分支回到根令牌。诊断包含分支及实际解析值。
3. **验证** — 审查给出的 `.a = 4px` / `.b = 600` 分别被点名；混合有效分支、未遮蔽根令牌分支及深色环境局部定义测试通过；聚焦和完整路由检查结果见上。
4. **后续** — 本条修复无后续工作。保留复杂选择器及跨选择器特异性未建模的边界。
