- 诊断阶段曾把第一帧 AX 空壳当作检查对象，该结果已撤回，不计入有效红灯。测试现在等待实际控件／状态，避免用固定首帧推断产品行为。

## 中文墨迹测试的有效性

采样的是 TextEditor 实际缓存位图中字符框上部 45% 的不透明深色像素，并与同编辑器同样文字的第二行比较；90% 比例容差处理行基线和抗锯齿差异，不以声明的内边距作为通过条件。长文本滚到开头后读取首行。测试窗口固定浅色，实际 backingScaleFactor 为 2。

受控实验临时覆盖输入框顶部 16 pt，不改变字符布局；24 组多行对照均因首行墨迹为 0、第二行仍有正值而失败（“创建，连线”对照为 374）。实验覆层已恢复，不属于产品修正，不是用户问题的独立复现，也不报告自动 Swift mutation score。

恢复后 72 组对照全部通过，最小墨迹比例为 0.9665071770。实际全量公共入口 `sh scripts/test-native.sh`：460 tests／97 suites，172.921 秒通过；App 覆盖 9826／10775（91.192575%），79／79 文件，report-only。报告生成于 2026-11-01T13:50:46.841Z。
