# #929：AI 新增内容保持当前分集

## 范围与证据

目标是清除分集后执行「根据剧情增加新的节拍」不恢复旧集，且保留明确的分集请求、预览确认和复合撤销。#931 的关联节点自动归集属于不同触发场景，本次不改变归集算法。

已确认：节点工厂不默认填写集号；清除字段走普通可撤销补丁；AI 摘要未标注未分集，通用创建示例携带第 1 集；批次边界只校验集号形状。原始供应商载荷与运行版本未提供，因此不能确认现场究竟采用历史值还是示例值；使用固定供应商响应验证夹带旧集号的可达路径。
