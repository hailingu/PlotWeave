两端分别在宿主从磁盘读取最终媒体并独立计算 SHA-256，与页面输入摘要完全相同：10 MiB 级 `2638e2b1eb8058f8f6232b6d3d5bef2aea44072e93aac74acf240e222e3bcf25`，20 MiB 级 `9d3d5f217d75968b0dae80a6be91ae7747803739ec8ffa8791412cc24ed9bbda`。图片生成在计时前，摘要计算在导入计时后；定时器和rAF快照在导入结束时冻结，避免把摘要等待计入活动计数。Tauri 两例均为页面 visible 且 hasFocus=true；WK 两例页面 visible、hasFocus=false，rAF 仍连续更新。

该测量没有旧版本实测对照，也没有跨设备、多轮分位数、峰值内存、主线程原生profile、真实用户图片解码/缩略图或手工忙碌动画验收；不能推导冻结的旧时长或声称零卡顿。自动回归的1秒最大定时器间隔是防长冻结的宽松守卫，不是16.7ms视觉流畅承诺。20 MiB精确字节上限另由边界回归覆盖；此表采用真实有效 BMP，略低于20 MiB。

红绿证据：生产修改前，Tauri与Swift桥测试都因131,075字节单帧超过65,536而失败；实现后原库门面与新分块回归共34项通过，随后增加失败及诊断回归。宿主成功、边界、错序、取消、过期、并发槽位以及最终提交失败后的重用继续通过各层验证。最终全量与门禁状态在任务交付时报告。

并行桌面回归期间还观察到另一轮 Tauri 的定时器最大间隔 212/531 ms、rAF 为0；原生既有焦点用例也失败，未将其视作稳定前台测量或归因为产品冻结。测试现保留页面可见性与焦点字段，以上最终数据在两宿主UI回归串行运行时取得；先前断线、超时及主动终止的运行没有被计为通过。
