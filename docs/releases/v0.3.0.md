# PlotWeave v0.3.0

发布当前已有的 SwiftUI/AppKit 原生界面、Swift 业务服务与 React Flow 画布实现；本次准备仅同步版本、锁文件、原生 bundle 断言和发布文档，不增加功能。

## 版本选择与源码范围

选择 **0.3.0**：相对 [v0.2.0](https://github.com/hailingu/PlotWeave/releases/tag/v0.2.0)，已有实现包含原生外壳与服务迁移、保存反馈、资产协调和多项合同／工程改进，属于新的次版本，不是单项补丁。`0.x` 仍不承诺 1.0 稳定性。

功能冻结基线为 `dev` [`4e17c1c198aa8150c87473849d61e92692083777`](https://github.com/hailingu/PlotWeave/commit/4e17c1c198aa8150c87473849d61e92692083777)。发布准备经任务 PR 进入 `dev`，再经 `dev → main` 集成 PR；最终新 tag 必须精确指向通过 push CI 的 `main` 合并提交，实际 SHA 与运行链接见 GitHub Release。既有 v0.2.0 tag 保持不变，不沿用历史文档重定位例外。

此次 GitHub Release **仅提供源码 tag 与自动生成的源码归档，不附二进制安装包**。不新增签名凭据、公证配置、分发平台或安装承诺。

## 相对 v0.2.0 的主要已有变化

- **原生应用**：SwiftUI 首页、工具栏、大纲、检查器、设定、图库、AI、导出与设置；AppKit 管理窗口和系统交付，WKWebView 承载 React Flow。迁移经 [PR #526](https://github.com/hailingu/PlotWeave/pull/526) 合入 `dev`，原生应用使用 Swift 服务，不链接 Rust 或历史 C ABI。
- **编辑与保存**：React 继续拥有唯一编辑文档、撤销历史与保存协调；原生界面发送意图并读取投影。保存中／失败／重试反馈、退出排空、区域异常恢复及稳定目标处理均来自已有实现。
- **资产与模型**：图库导入／删除失败协调、部分成功回执、项目资产合同、媒体响应隔离，以及图片下载地址／重定向边界已修复；Provider API 的本地／自建服务能力保留。
- **画布更新**：加载准备、原生编辑投影记忆与共享大纲缓存减少同序位置帧的重复派生和序列化；真实跨序、内容及其他投影字段仍即时更新，不承诺每帧零图规模成本。
- **验证与工程**：双 Rust workspace 依赖漂移检查、服务器端门禁证据核验、固定依赖审计工具与 Action SHA、前端原生画布逐文件覆盖率、native 独立覆盖率报告及 CPU 预算均已落地。

临近发布的 [PR #701](https://github.com/hailingu/PlotWeave/pull/701)、[PR #702](https://github.com/hailingu/PlotWeave/pull/702)、[PR #703](https://github.com/hailingu/PlotWeave/pull/703) 分别修复资产操作结果协调、卸载保存／回调稳定性及原生编辑投影复用；#698–#700 已关闭。`docs/quality-assessment.md` 是独立滚动评估记录，其后续更新不改写为本版验收结论。

完整能力和磁盘／IPC 合同分别见[当前功能状态](../swiftui-react-flow-current-state.md)、[数据模型](../data-model/README.md)和[界面设计](../ui-design.md)；本页不新增合同或功能承诺。

- **#699 hosted 布局异常根因未确认**：此前出现 SwiftUI `Update Constraints` 崩溃；同一源码的一次受控、钉版 Xcode 27.0 重跑及后续 dev CI 成功，原始失败保留。本地 Xcode 27.1 完整诊断出现 `activeSpace`／AX 环境失败，不能写成通过；也不能据后续成功声称根因已修复。
