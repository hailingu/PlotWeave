# PlotWeave v0.3.0

本版以源码形式发布 SwiftUI/AppKit 原生应用与 React Flow 画布：在 macOS 上组织短剧、分集、角色与剧情分支，管理素材，使用可选 AI 服务，并导出剧本。

**仅发布源码 tag 与 GitHub 自动生成的源码归档，不附二进制安装包。** 源码构建不代表已经完成 Developer ID 签名、公证或安装验收。

## 相对 v0.2.0 的主要变化

- **macOS 原生创作界面**：SwiftUI 提供项目片库、大纲、检查器、设定集、素材库、AI、导出与应用设置；AppKit 承接窗口和系统交付。WKWebView 内的 React Flow 保留唯一编辑会话与撤销历史；Swift 服务承接存储、素材、设置、密钥和模型请求。Tauri/Rust 为保留基线，原生应用不链接 Rust 或历史 C ABI。
- **故事编排**：六类节点、分集与大纲、剧情流与多结局、对齐和吸附；大纲拖放、节点归集、空集及清空字段的处理得到修正，避免无效操作改变原有剧情关系。
- **项目与保存反馈**：首页加载和局部失败反馈、保存失败与重试、退出排空及画布重载恢复；项目复制、素材操作与独立 AI 会话保存的竞态和部分成功协调得到修正。
- **素材与模型**：项目／图库资产引用、导入／删除及回执恢复、媒体读取隔离、图片下载 URL 与重定向检查；保留自配 Provider 和本地／自建 API 服务能力。AI 的发送反馈、工具修改、分集归属及会话重建后的保存等待得到修正。
- **产品入口**：README 聚焦产品能力、创作流程和获取方式，新增[快速上手](../guide/quick-start.md)，工程说明集中至[开发文档](../development/workflow.md)；Wiki 同步当前能力、分支与文档入口。
- **工程验证**：双 Rust workspace 依赖漂移检查、服务端门禁证据核验、原生画布逐文件覆盖率、native 独立覆盖率报告，以及 `/ub-mode` 发布前检查均已接通；开发集成分支名称已由历史 `dev` 改为 `develop`。

近期修正包括 [PR #943](https://github.com/hailingu/PlotWeave/pull/943)（AI 内容分集）、[PR #944](https://github.com/hailingu/PlotWeave/pull/944)（原生界面与焦点）、[PR #953](https://github.com/hailingu/PlotWeave/pull/953)（图归一化）和 [PR #956](https://github.com/hailingu/PlotWeave/pull/956)（AI 会话重建后的保存等待）。完整差异以版本 tag 为准；[滚动质量评估](../quality-assessment.md)及历史日志不等同于本版全部验收完成。

## 已知限制

- 官方支持 macOS。原生运行需要 macOS 26.0+，构建使用 Node.js `^24.18.0 || >=26.0.0`（默认 24.18.0）和 Xcode 27.0／macOS SDK 27.0。其他本机 Xcode 版本的诊断不能替代固定 CI 工具链结果；Windows 不受支持，Linux 未验证。
- 原生数据位于独立的 `dev.plotweave.PlotWeaveNative.development` 根，不读取旧 Tauri 数据或历史 Keychain，不承诺自动迁移；AI Provider 需要重新配置。
- 真实公网 TLS、计费模型、系统文件／保存面板选址与真实中文输入法仍有人工验收缺口。VoiceOver 不支持；视觉快照验收已取消，现有语义、键盘、外观和几何回归继续保留。
- 历史首拖合成输入样本仍出现超过 33ms 的帧间隔；不声称无卡顿，也不把有限 Debug 自动样本当作真实触控板／HID、高刷新率、大图或 Release 配置性能验收。
- JSON 导出包含资产引用，不包含媒体字节或独立 AI 会话，不是完整备份；JSON 导入、视频制作、资产收藏回库尚未实现。AI 取消为协作式，不保证远端计费请求停止；未落盘编辑与进行中的生成作业不保证跨重启恢复。
