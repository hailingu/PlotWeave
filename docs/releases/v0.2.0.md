# PlotWeave v0.2.0

PlotWeave 首个公开源码版本：面向短剧创作，将场景、对白、角色与分支剧情组织为可编辑画布。

## 版本与发布决策

仓库所有者于 2026-10-02 明确要求「PR #489 已经合并，将 dev 合并进 main，并新增一个合适的 release 版本」。该决策先于首次面向 `main` 的 PR，按原分支策略启用发布线。发布准备先经任务 PR 进入 `dev`，再由 `dev → main` 集成 PR 发布。

选择 **0.2.0**：前端清单及锁文件、Rust 清单及锁文件、Tauri 配置原本均为该版本，且仓库此前没有 tag 或 GitHub Release。首发保留一致版本，无需无功能变更地另增版本号；`0.x` 表示产品仍在演进，不承诺 1.0 稳定性。

## 本版能力

- 节点画布：场景、桥段、对白、分支与多结局编排，角色及设定管理，分集与创作大纲。
- 项目本地持久化、自动保存、撤销重做、媒体资产引用与素材管理。
- Markdown 剧本导出及可选创作大纲/分镜附录；JSON 导出当前会话的 `ProjectDocument v1`，包含未保存编辑、分支、布局、视口、设定与资产引用。
- 多选节点六方向对齐、22 单位网格吸附及自由拖动切换。
- 可配置 AI 服务与画布文生图；生成结果写入项目资产，支持输入变化守护及协作式取消。

[PR #489](https://github.com/hailingu/PlotWeave/pull/489) 完成对齐、吸附与 JSON 导出；其中 [d38a999](https://github.com/hailingu/PlotWeave/commit/d38a999d34bc768df20d84dced55479307c61f4d) 修复导出弹窗打开期间视口动画完成后 JSON 陈旧的竞态，回归覆盖完成视口、复制/下载载荷、保存与卸载冲刷的一致性。

## 交付与验证范围

此次 GitHub Release 提供源码 tag 与 GitHub 自动生成的源码归档，**不附二进制安装包**。本地 Tauri 构建仅用于验证，实际执行结果及绑定提交的 CI 链接记录在发布 PR 和 GitHub Release 中；它不代表 Developer ID 签名、公证或安装验收。

发布必须完成本地提交/推送门禁（静态检查、前端/Rust 覆盖率及 SonarQube）和 PR CI，并在合并后等待 `main` push CI 成功。`ci.yml` 同时覆盖 `dev` / `main` 的 PR 与 push；未新增发布凭据、签名配置或更改分支保护设置。

## 已知边界

- macOS Tauri WebView 的实际文件下载落盘、触摸拖拽尚未人工验收。自动化中的下载 Blob、文件名、MIME、剪贴板与真实鼠标事件验证不能替代这两项原生检查。
- JSON 包含媒体资产引用，不包含媒体文件本体或独立 AI 会话，不是完整备份包；本版不新增 JSON 文件导入入口。
- AI 图像生成需要自行配置服务；进行中的生成任务不跨应用重启或编辑器卸载恢复。取消为协作式，不保证远端计费请求停止。
- macOS 原生视觉增强、图生图、视频节点及跨重启任务恢复仍为后续方向。Windows/Linux 分发未验证。
- 首发准备期间安装开发依赖时，npm 审计报告 `brace-expansion` 与 `js-yaml` 两个开发工具链间接依赖存在高危拒绝服务公告。它们不在生产依赖树中（`npm audit --omit=dev` 为 0 项漏洞）；未在本次发布中升级依赖，也未将完整审计报告描述为全绿。开发环境处理不可信 glob/YAML 输入时需留意这些已知问题。

开发运行环境及命令见 [README](../../README.md#快速开始)。桌面二进制发布需另行完成目标平台打包、签名/公证（适用时）、安装启动与原生关键流程验收。
