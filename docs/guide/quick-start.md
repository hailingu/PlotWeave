# PlotWeave 快速上手

本指南介绍 v0.3.0 的创作流程。当前仅提供源码，macOS 26.0+ 用户需先按[构建与运行指南](../development/workflow.md#native-application-launch-and-verification)启动应用；源码归档不是安装包。工具链、工程命令与贡献规则统一见[开发文档](../development/workflow.md)。

## 1. 创建或打开短剧

在欢迎页选择“新建短剧”，或者选中已有项目后点击“打开项目”。项目片库支持改名、复制和删除；删除项目会连同项目画布、AI 会话和项目资产一起删除，且无法撤销。

首次使用时可打开内置合成示例“午夜出租车”了解画布。它只是展示节点和剧情编排方式的示例，你可以创建自己的故事。

## 2. 用节点搭建故事

通过“添加节点”选择需要的内容：

| 节点 | 用途 |
| --- | --- |
| 节奏卡 | 梳理故事节奏、阶段与转折 |
| 场景 | 描述一场戏的环境和事件 |
| 对白 | 编写人物对话 |
| 分支 | 组织选项与不同剧情走向 |
| 分镜 | 补充镜头设计 |
| 图片 | 放置视觉参考或生成的图片 |

选择节点，在检查器中编辑属性；用连线表达剧情走向。通过大纲按分集查看内容，缩放画布检查整体结构。可以拖动、多选、对齐或自动排布节点，使用撤销与重做调整创作。

## 3. 完善设定与素材

打开“设定集”管理角色、地点与文档，并与剧情内容关联。打开“素材库”导入和整理参考图片，再在项目中使用相应资产。

项目会保存到本机。留意保存状态；失败时先按界面提示重试，确认保存完成后再退出。未保存的编辑不保证在崩溃或重启后恢复。

## 4. 按需启用 AI

在应用设置中配置兼容的 Provider、服务地址、API Key、可用模型及默认模型。基础画布编辑、设定管理与导出可以不配置 AI。

进入“AI”进行对话；对于修改项目的提议，先检查预览再执行。图片节点可请求生成角色参考、场景底图或分镜关键帧，结果保存为项目资产。请求可能产生所选服务的费用；取消是协作式操作，不保证远端请求或计费立即停止。

原生应用与旧 Tauri 应用的数据及凭据隔离，不自动读取旧项目或密钥；使用原生应用需重新配置 Provider。迁移范围见[开发运行说明](../development/workflow.md#native-application-launch-and-verification)。

## 5. 导出剧本

点击“导出”，选择格式并检查预览：

- **Markdown**：面向阅读与分享的剧本正文和分镜附录；开启“创作大纲（节奏与分支）”可加入节奏、分支及分集信息。
- **JSON**：保留当前会话的节点、连线、布局、视口、设定与资产引用，便于结构化处理。

根据需要复制全文或保存文件。JSON 不包含媒体字节或独立 AI 会话，也没有对应的文件导入入口，因此不能替代项目及媒体的完整备份。
